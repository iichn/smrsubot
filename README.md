# P.MRSU Telegram Bot

Telegram-бот для образовательного портала МГУ им. Н.П. Огарёва (p.mrsu.ru), предоставляющий быстрый доступ к расписанию и уведомлениям.

### Стек
- Python
- Aiogram
- Aiohttp
- SQLite

### Ключевые функции
- Получение актуального расписания занятий.
- Автоматическая ежедневная/еженедельная рассылка расписания.
- Уведомления о новых сообщениях на форумах дисциплин.

### Установка и запуск
```bash
pip install -r requirements.txt
python bot.py
```

### В этом проекте я реализовал
1. Получение актуального расписания выбранную дату или целую неделю.
1. Настраиваемую рассылку расписания.
2. Основным отличием от оригинального портала p.mrsu.ru является реализация системы уведомлений о новых сообщениях на форумах дисциплин.
